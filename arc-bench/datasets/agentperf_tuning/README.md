# `agentperf_tuning` — AA-AgentPerf tuning subset (50 trajectories)

This dataset contains 50 multi-turn agentic-coding trajectories
generated following the
[Artificial Analysis AgentPerf](https://artificialanalysis.ai)
methodology:

> Realistic multi-turn workloads with reasoning + tool calls and
> variable context. ISL ~1K-131K (mean ~27K), OSL median ~150
> tokens (P95 ~2K), 12+ programming languages.

It is used by Arc's `arc-bench` crate to drive its
`TrajectoryReplayer` against any inference vendor (Arc, vLLM, sglang,
TGI, ...) and report TTFT / output-speed / token metrics per turn.

The 50 trajectories are the smaller "tuning" subset; a larger
"evaluation" subset will live alongside this directory once the
methodology is fully formalized.

## Provenance and licensing

Every trajectory's JSON file carries a `source` field naming a real,
public, permissively-licensed repository (MIT / Apache-2.0 /
BSD-3-Clause / BSD-2-Clause / EPL-2.0 / Zlib / LGPL-3.0). The file
contents recorded inside `tool` turns are representative snippets of
the listed file from the listed commit/tag — short enough to fall
under fair use for benchmarking purposes and always attributed back
to their source.

The list of source repositories is in [`licenses/SOURCES.txt`](./licenses/SOURCES.txt);
each source repo's project-level LICENSE file is preserved verbatim in
`licenses/` for completeness.

The trajectories themselves were generated by Qwen3-Coder-480B-A35B-Instruct
on 2026-05-23 from a fixed set of prompts that simulate a developer using
an AI coding assistant. The conversation transcripts, tool invocations,
and synthesized file-edit responses are derived works; we distribute them
under Apache-2.0 alongside the rest of the Arc engine. If you are the
maintainer of a referenced repository and would like attribution corrected
or content removed, please open an issue against
`github.com/aeonmindai/arc`.

## Regenerating

```
cargo run -p arc-bench --bin generate-agentperf-tuning
```

The generator is idempotent. The on-disk JSON files are the canonical
artifacts; the generator is a build tool kept in the repo so we can
extend the dataset.

## File format

See [`arc-bench/src/trajectory.rs`](../../src/trajectory.rs).

A minimal trajectory looks like:

```json
{
  "id": "agentperf_tuning_001",
  "language": "rust",
  "source": {
    "repo": "github.com/example/repo",
    "license": "MIT",
    "commit": "<sha>"
  },
  "generated_with": {
    "model": "Qwen3-Coder-480B-A35B-Instruct",
    "date": "2026-05-23"
  },
  "turns": [
    {"role": "user", "content": "Refactor ..."},
    {
      "role": "assistant",
      "content": "I'll first read the existing implementation.",
      "tool_calls": [
        {"id": "call_1", "name": "read_file", "args": {"path": "src/lib.rs"}}
      ]
    },
    {"role": "tool", "tool_call_id": "call_1", "content": "<file contents>"},
    {"role": "assistant", "content": "Now I'll rewrite..."}
  ]
}
```
